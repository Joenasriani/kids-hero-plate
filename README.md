# Hero Academy: Healthy Plate

Hero Academy: Healthy Plate is a 10-round food-classification game.

## How it plays

Each run randomly selects 10 food or drink items from a built-in bank of 19. For each item, the player chooses between the game's two categories: **healthy** or **unhealthy**.

**random item → choose category → compare with built-in label → score → next item → final result**

A matching choice adds 10 points. The maximum score is 100, and the final screen selects feedback from score bands.

## Item bank

The current game includes apples, candy, broccoli, water, soda, carrots, pizza, donuts, strawberries, fries, eggs, burgers, watermelon, ice cream, grapes, corn, oranges, cake and hot dogs.

## Content note

The `healthy` / `unhealthy` values are simplified game labels, not a complete nutrition standard or individualized dietary assessment.

## Implementation

The playable game is contained in `index.html`.
